# منصة نماذج الموارد البشرية — بيت هايل

موقع واحد يحتوي على 41 نموذج HR جاهزة للطباعة (A4)، بتصميم موحّد، مع تعبئة تلقائية لبيانات الموظف من ملف إكسل.

## قواعد التصميم
- **كل نموذج في الموقع يجب ألا يتجاوز صفحة A4 واحدة عند الطباعة**، باستثناء نموذجين فقط:
  - **الوصف الوظيفي** (`job-description`) — يُسمح له بأكثر من صفحة حسب طول المحتوى.
  - **عقود العمل** (تصنيف `contracts`) — عقد العمل الرسمي متعدد الصفحات بطبيعته (4 صفحات ثابتة).
- التنسيقات المشتركة (`row`, `kv`, `section-title`, `doc-table`, `sign-grid`, `para`, `doc-header/footer`) على مقاساتها الطبيعية المريحة — لا تُصغَّر بشكل عام.
- النماذج التي يطول محتواها بطبيعتها وتحتاج ضغط إضافي لتبقى بصفحة واحدة (حالياً: `settlement-data`, `vacation-dues`, `investigation-record`) مُغلّفة بكلاس `compact-doc` الذي يطبّق تنسيقاً أكثر إحكاماً *فقط* عليها، دون التأثير على باقي النماذج القصيرة. عند إضافة نموذج جديد طويل يتجاوز صفحة واحدة، غلّف محتوى `render()` بـ `<div class="compact-doc">...</div>` بدل تصغير التنسيقات العامة.
- نموذج عرض العمل (`job-offer`) له تنسيقه الخاص المستقل (`jo-*`) وهو مضبوط أصلاً على صفحة واحدة بمقاساته الخاصة.

## الملفات
```
index.html              → الصفحة الرئيسية (لا تعدلها إلا إذا لزم)
assets/app.js           → محرك الموقع (تسجيل الدخول، البحث، الطباعة)
assets/forms-data.js    → تعريف كل النماذج الـ41 ونصوصها
assets/style.css        → التصميم والتنسيق (بما فيه تنسيق A4 للطباعة)
assets/xlsx.full.min.js → مكتبة قراءة إكسل (SheetJS) - لا تحتاج إنترنت
assets/logo.png         → شعار الشركة
Staffdata.xlsx          → ملف بيانات الموظفين (هذا هو الملف الذي تحدّثه أنت دوريًا)
```

## كيف تنشره على GitHub Pages
بما أنك تستخدم GitHub Desktop مع مستودع `HAIL-HOUSE-HR` حاليًا، الطريقة الأسهل:
1. أنشئ مجلد جديد داخل نفس المستودع، مثلاً: `HR-Forms/`
2. انسخ كل الملفات أعلاه داخله (حافظ على نفس أسماء المجلدات: `assets/`)
3. من GitHub Desktop: Commit ثم Push
4. الرابط سيكون: `https://mohx94.github.io/HAIL-HOUSE-HR/HR-Forms/`

## تحديث بيانات الموظفين
كل ما عليك فعله هو استبدال ملف `Staffdata.xlsx` بنسخة محدثة (بنفس الأعمدة والترتيب)، ثم Commit + Push من GitHub Desktop. الموقع يقرأ الملف مباشرة عند كل فتح — لا حاجة لتعديل أي كود.

⚠️ يجب أن يحتفظ الملف الجديد بنفس أسماء الأعمدة بالضبط الموجودة في النسخة الحالية (نفس شيت "data" من ملفك الأصلي).

## تغيير كلمة المرور
كلمة المرور الحالية للدخول: `HailHR2026`
لتغييرها: افتح `assets/app.js` وعدّل أول سطر:
```js
const SITE_PASSWORD = "HailHR2026";
```
⚠️ هذه حماية بسيطة فقط (تمنع الدخول العرضي) وليست تشفيرًا حقيقيًا — أي شخص يفتح "عرض المصدر" في المتصفح يمكنه رؤيتها. لا تضع بيانات حساسة جدًا تعتمد على هذه الحماية فقط.

## إضافة أو تعديل نموذج
كل نموذج في `assets/forms-data.js` هو كائن JS بهذا الشكل:
```js
const FORM_MثAL = {
  id:'unique-id', cat:'certificates', titleAr:'اسم النموذج',
  manualFields:[ {key:'date', label:'التاريخ', type:'date'} ],
  render(emp, m){ return `... HTML ...`; }
};
```
- `emp` = بيانات الموظف المحددة تلقائيًا من الإكسل (الاسم، الراتب، تاريخ الانضمام...)
- `m` = القيم التي يدخلها موظف الموارد البشرية يدويًا (تواريخ خاصة بالحالة، مبالغ، أسباب...)
- بعد إنشاء الكائن، أضفه إلى قائمة `FORMS` في نهاية الملف

## ملاحظات مهمة
- الموقع لا يحفظ أي "سجل طباعة" (تم الاستغناء عن هذه الخطوة بناء على طلبك)
- الدخول بكلمة مرور مشتركة واحدة لكل القسم (بدون حسابات مستخدمين فردية)
- كل نموذج يفتح بتنسيق A4 جاهز للطباعة مباشرة (زر "طباعة A4")
- ملفات العقود (6 نماذج) تتضمن كامل بنود عقد العمل السعودي القياسي (المهنة، المدة، الأجر، الالتزامات، الأحكام العامة) بالعربي والإنجليزي جنبًا إلى جنب
